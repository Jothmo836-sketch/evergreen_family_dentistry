# Evergreen Family Dentistry

A modern dental clinic website for Evergreen Family Dentistry in Yreka, California.

## Run locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Build for production:
   `npm run build`

This project is a static Vite app and can be hosted on any standard static hosting provider such as Netlify, Vercel, GitHub Pages, or any web server that serves the built files from the `dist` directory.
